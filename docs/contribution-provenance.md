## Human direction and AI output — 2026-10-29

This project is an experiment in building software publicly with AI assistance. Salil Harit sets the product direction and makes the decisions. Codex assists with research, drafting, scripts and implementation proposals. The public announcement is on [LinkedIn](https://www.linkedin.com/posts/salil-harit_softwareengineering-aiagents-opensource-share-7521111288710627328-0xVy/).

### Direction given by Salil

The [decision register](decisions/decision-register.md) records the earlier requirements and their basis:

- Build an open-source inventory system for small and midsize businesses across sectors, including manufacturing and pharma.
- Allow physical stock entry without an original bill, using the same entry workflow as stock with paperwork.
- Use local PostgreSQL and research existing systems' tables and fields before implementing the schema.
- Investigate operational roles, day-to-day problems, audit needs, ERP integration and India-based international trade scenarios.
- Keep the product reasoning, engineering decisions, proposed tables and contribution history understandable and reviewable.

In the current conversation, Salil explained that the experiment should increase his public visibility by showing the process and engineering diligence behind AI use. He then requested a simple record of his direction versus AI output, followed by a commit and push.

### Work produced with AI assistance

The repository currently contains AI-assisted research and design artifacts:

- Product framing, stakeholder/workflow research, source summaries and proposed release scope.
- Comparisons of existing systems' schema declarations, with source URLs and pinned upstream commits.
- A proposed database dictionary, table/column audit, relationship diagrams, and compliance/trade design notes.
- Proposed posting, concurrency and ERP integration contracts, including cases that future tests must verify.
- Decision records, the table discussion queue and documentation navigation.
- Python scripts for source-field research, research rendering, schema-audit generation and documentation navigation.
- A dbmate workflow and an initial migration that creates only the `ims` namespace. The baseline was generated using the CLI; it does not create the proposed business tables.

These artifacts translate the human requirements into drafts and technical proposals. They should not be described as independently designed, manually written or fully verified by Salil. This summary uses the recorded requirements and repository artifacts; it is not a prompt-by-prompt transcript or an exact attribution of every line. Earlier agent interventions and manual edits have not been measured separately.

### What has and has not been demonstrated

Research sources and proposed decisions are recorded for inspection. The repository is still at the research and database-design stage: no inventory application or business-table implementation exists, no live database migration or concurrency test has been performed, and no operator interviews or pilot results have been recorded. Proposed verification cases are not passing tests. Human direction does not imply that every generated detail has been approved.

The AI suggested making bill-independent receiving the next small implementation milestone and publishing the acceptance criteria, interventions and verification results. That remains a recommendation, not an implemented feature or a confirmed task assignment.

For future milestones, record the task and acceptance criteria, what the agent produced, what Salil changed or rejected, the checks actually run, and what remains unresolved. This will make the degree of agent independence inspectable without claiming evidence that has not been collected.

## Research and schema draft — 2026-10-28

The project direction covers cross-sector inventory, local PostgreSQL, physical stock entry without mandatory bills, concurrency, traceability, and ERP integration.

Research records identify public sources and exact upstream commits. The schema dictionary, table inventory, compliance addendum, and posting contracts are proposals for discussion. A namespace-only migration has been generated; no live database migration or concurrency test has been performed.

The source-field extraction recorded 506 direct declarations across 12 source files. Inherited and dynamically contributed fields may be absent. Public operator reviews and documentation inform stakeholder hypotheses; no operator interviews or pilot validation have been performed.
